# Prístupové systémy

Technické realizácie prístupových a dochádzkových systémov.

## Projekty

Postupne tu budem pridávať jednotlivé realizácie, fotografie, použitý materiál a technické riešenia.

## Čo obsahujú projekty

🔑 Prístupové čítačky a identifikačné prvky

🚪 Elektrické a elektromagnetické zámky

🎛️ Riadiace jednotky

🔌 Napájacie zdroje a kabeláž

💻 Konfigurácia a nastavenie systému

📷 Fotografie z realizácie

## Bezpečnosť

Zverejnené projekty neobsahujú citlivé údaje, prihlasovacie údaje ani informácie, ktoré by mohli ohroziť bezpečnosť objektu.
